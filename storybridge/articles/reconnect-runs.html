초기 구독의 대기·DB·callback과 비용

다음 SQL Questions·구독 거절·단계 시간은 초기 연결·워밍업·추가 관측을 포함한 전체 실행 누계다. CPU/백만 수신은 측정 구간 CPU 평균을 그 구간의 실제 메모리 수신 처리량으로 나눈 근사치이며, 서로 다른 구간의 분자를 나누지 않는다. 소켓 쓰기 배치에는 신규 구독 단계 timer가 없어 0ms로 채우지 않는다.

focus는 인기 방 999, other는 일반 방이다. wait는 작업 제출 전부터 worker 실행까지로 thread scheduling도 포함한다. query는 Store.subscription 호출의 권한 확인·JDBC 왕복·결과 해석 경과시간이며 MySQL 내부 실행 시간만은 아니다. callback은 peer monitor 획득·구독 등록·READY 전송 큐 등록까지이고 실제 socket write는 포함하지 않는다. MySQL 내부 비용은 각 실행의 mysql-digests.json과 함께 대조한다. 이 서버 경과시간을 k6 시각과 직접 빼지 않는다.
